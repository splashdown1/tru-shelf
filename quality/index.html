Source lineage and limits

v43 is a deterministic static update to v40: it replaces the embedded LOGOS Lexicon pack with a source-verified repaired pack, adds selected plural fallback and the Text-Rooted Understanding identity answer, and retains the local Scripture teaching shelf. v44 is a pinned static patch to v43 that addresses repeated GAP guidance, routes a verified personal-status follow-up to the KJV word index without answering the personal question, and shortens repeated voice-mismatch notices. v45 is a pinned presentation-only patch to v44: it cleans the display of original-language entries, presents a bounded topical answer with linked KJV evidence for “where is heaven?”, and tightens mobile header layout. v46 is a pinned portal patch to v45: the gold control opens the searchable TRU family index in the same tab, browser Back returns to the reader, and the architecture reply names that destination. v46 changes no embedded sources or reader routing and does not establish full source completeness, theological correctness, or general-purpose performance.
