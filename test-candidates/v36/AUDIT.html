TRU v36 audit

Versioned human-test candidate for grounded Bible questions of five or more words. It adds a narrow natural-language routing layer over the existing offline corpus.

Change set

  • Recognised hope, forgiveness, love, peace, fear, courage, mercy, rest, truth, prayer, and selected Bible-specific phrases are routed to existing local topic, lexicon, or KJV sources.
  • Jesus-and-forgiveness questions use the existing locally red-letter-indexed forgiveness excerpts. Loving-enemies and love-one-another questions return only their relevant KJV passages, avoiding the Luke 19:27 false positive.
  • Explicit Strong’s references and “peace in Hebrew” use the existing lexicon data.
  • Non-Bible/live-information requests receive an explicit local-source boundary; math questions retain the existing Mathematics route.
  • No embedded Bible, lexicon, topical, dictionary, or other source data changed.

Verification

  • Deterministic builder pins v35 SHA-256 c738c0d3fc305f523a3f34da1ae1381c0fc618e47319dd88ed96041ac42b09f3.
  • Verifier confirms all 11 embedded source/data blocks are byte-identical.
  • The 29-case five-plus-word pilot reports 26 targets passed, 0 failed, and 3 cases deferred for human review.
  • Browser smoke tests confirm the five-word hope answer, exact Jesus passages without Luke 19:27, the forgiveness card, and an explicit live-price scope boundary.

Limits and links

This is a bounded router, not open-ended reasoning. Three benchmark questions still need human interpretation. This artifact-based candidate does not resolve the missing matching v17 modular source tree.
