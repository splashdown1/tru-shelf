TRU v35 audit

Human-test candidate for exact one-word local lexicon lookup. It addresses a false positive where bare “English” matched an H853 gloss rather than an exact English index entry.

Change set

  • A bare one-token lexical query returns a match only if the term is an exact key in an English, transliteration or lemma index.
  • Unindexed “English” returns the explicit exact-match GAP instead of Hebrew H853.
  • Explicit Strong’s-code lookup remains available, including H853.
  • The app data, Math routing and exact “love” lexical query are unchanged.
  • The patch is pinned to the v34 artifact and updates only the exact lookup guard and build stamp.

Verification

  • Deterministic builder pins the v34 SHA-256 recorded in README.md.
  • Verifier confirms no embedded payload changed and known exact terms remain indexed.
  • Local browser smoke tests: “English” and “define English” return GAP; `math` returns Mathematics; explicit Strong’s H853 still resolves; `love` still returns its exact matches.
  • Public Pages verification is recorded after deployment.

Limits

This changes bare one-token lookup only; it does not redefine explicit Strong’s queries or broad “word study” behaviour. It is an artifact-based candidate and does not resolve the missing matching v17 modular source tree.
